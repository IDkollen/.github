# IDkollen

IDkollen erbjuder e-legitimering för telefon, kundtjänst och digitala flöden, med stöd för nordiska e-ID: BankID (Sverige och Norge), Freja eID, MitID och FTN. Mer än 500 företag i Norden använder IDkollen, bland annat inom vård, bank, finans, försäkring och handel.

IDkollen är det svenska varumärket. I övriga Norden heter vi [Identisure](https://github.com/Identisure).

## Tjänster

- **TeleID** - Identifiera kunder i telefon eller chatt, utan integration
- **TeleSign** - Signera avtal och fullmakter under samtalet
- **SafeMail** - Säkra meddelanden som kräver e-legitimering för att läsas
- **FormID** - Webbformulär som signeras med e-legitimation
- **REST API** - Legitimering, signering, åldersverifiering och ID-verifiering i dina egna system
